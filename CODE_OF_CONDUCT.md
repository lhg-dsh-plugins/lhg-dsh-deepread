# Code of Conduct

DeepRead is an open-source project for people with different backgrounds, languages, and levels of experience. We want participation to be useful, safe, and respectful.

## Expected behavior

- Be considerate and specific when giving feedback.
- Critique ideas and changes, not people.
- Respect different levels of technical experience and communicate without ridicule.
- Give credit for work, sources, and prior art.
- Keep bug reports, reviews, and discussions relevant to the project.
- Accept maintainer decisions about scope while remaining free to disagree constructively.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Sexualized language or imagery.
- Publishing another person's private information without permission.
- Deliberate disruption, spam, or repeated off-topic promotion.
- Misrepresenting generated output, security findings, benchmarks, or another contributor's work.

## Enforcement

Maintainers may edit, hide, or remove contributions that violate this Code of Conduct and may temporarily or permanently restrict participation when necessary.

Report conduct concerns privately through the maintainer contact options on the [project owner's GitHub profile](https://github.com/xiehuan123). Do not open a public Issue containing sensitive personal information. Reports will be reviewed as promptly and confidentially as practical.

This Code of Conduct applies in the repository and in public spaces where someone is representing the project.
